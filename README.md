# Get Rect

Experimental Android DJM recording app by Peppy. Independent project, not affiliated with Pioneer DJ or AlphaTheta.

## Download
Get the v0.6 debug APK from Releases. Android 8+ with USB host and ARM/ARM64 required. This is a debug-signed test build, not a production release. Mixer/device compatibility is experimental; test your setup before recording a set.

## Install
Download the APK on Android, allow installation from your browser or file manager, then install. Only install files from this repository.

## Build
Android SDK 35, JDK 17, NDK 27.2.12479018 and CMake 3.22.1. Open in Android Studio or use a compatible Gradle installation. No Gradle wrapper is included in the original project.
